# Nexora Bank — React JSX multi-page frontend

Separate React JSX pages are routed with React Router.

Pages: Dashboard, Customers, Branches, Accounts, Loans, Transactions, Audit Log, Reports, Money Operations.

## Run
1. Extract ZIP and open this folder in VS Code.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local Vite URL.

Frontend only. Dummy data lives in React state and resets on refresh. No MySQL backend or real banking integration. All currency is INR / ₹.
